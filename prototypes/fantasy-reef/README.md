# Fantasy Reef — 美术视觉样板 02

方向：**Stylized Semi-Realistic Underwater Fantasy Art**，风格化半写实奇幻海洋。

这是独立的本地美术样板，未接入正式页面、生产构建或 GitHub Pages。没有 Commit 或 Push。正式 HTML、CSS、JS、资源与部署配置均未修改。

## 打开动态样板

在项目根目录沿用原有方式：

```bash
npm start
```

浏览器访问：

**http://127.0.0.1:5173/prototypes/fantasy-reef/index.html**

若开发服务已经运行，直接打开上述地址，不必重复启动。Live Server 同样可用，右键本目录的 `index.html` 预览。推荐本地 HTTP 方式，确保 WebGL 可以读取透明素材；`file://` 的纹理加载限制取决于浏览器。

## 本轮美术选择

以用户最后提供的 **P2 蓝绿小鱼裁图**为鱼类造型与绘画材质依据。没有使用此前 P1 的超写实鱼。新样板不会引用 `../bioluminescent/assets/` 下的任何旧素材。

- **鱼是点缀**：三种独立造型（蓝绿礁鱼、荧光灯鱼、长鳍神仙鱼），默认 18 条，10–30 可调。以大小、游向、透明度与运动相位变化融入场景；小眼睛、柔和鳞片，不做超写实标本。
- **珊瑚是主要美术元素**：枝状、扇状、管状、褶叶珊瑚与海葵、珊瑚虫共存。背景画有远中景礁壁与生态，近景透明贴图形成遮挡与视差，局部海葵软组织轻摆。
- **水母是动态主角**：两只水母共享新绘画素材，使用不同大小、透明度、漂移与呼吸相位；青蓝、淡紫的内部光，胶质伞盖缓慢收缩，口腕与细触丝连续流动。
- **空间统一**：蓝色水雾把远景压低，较清晰的珊瑚近景框住中央水体；增加缓慢光束、微粒与轻微指针视差。

三张早期海洋参考的分析仍用于空间与生物层次：第一张的放射伞盖及细丝/褶皱口腕，第二张的重量与柔和水下反光，第三张的珊瑚形态差异、近中远景与通透海流。最终材质统一服从最新 P2 的游戏插画方向；鲸鱼不在此次样板范围内。

## 互动

- 点击海水或“轻点投喂”：三种鱼都参与群游和追食；统一数量滑块控制总数。
- 暂停 / 恢复、日间 / 深海切换、内部微光、美术说明及原有纯净观赏。数量、主题与微光保存在本地。
- 快捷键：空格暂停，G 投喂，H 隐藏/显示界面。控件获得焦点时优先保留原生键盘行为。
- 系统开启减少动态效果时初始暂停；标签页在后台时停止动画帧，回到前台恢复。

## 技术边界

不是完整 3D 场景。使用 Canvas 2D 合成环境与粒子，一个小型 WebGL 2D 贴图网格进行局部连续形变，避免分条图片的透明接缝；没有相机、三维模型、骨骼系统或第三方渲染框架。

`fish-school.js` 在 V1 Boids 的基础上实现分鱼种的聚合、速度对齐、分离、追食与平滑转向；正式项目原 Fish 类保持原样。`scene.js` 接入新行为与绘画素材。`warp.js` 将素材绑定到 40×56 网格，身体、尾鳍、长鳍分别协调变化。水母与珊瑚的原位移分支保持不变。GPU 不可用时降级为 Canvas 尾/鳍摆动及水母整体漂浮/呼吸，细节形变会减少。

静态背景缓存在离屏画布；纹理仅上传一次并复用；WebGL 表面固定 1024×1024，并只清理当前贴图所用区域。主画布像素密度上限桌面 1.5 / 窄屏 1.4。没有新增项目依赖或 API 请求。六张素材合计约 9.9 MiB，首次本地加载后在浏览器内绘制。

## 素材与验证

原四张素材与新增两张鱼种素材位于 `assets/`，由内置 **image_gen** 生成，完整提示词保存在 `asset-prompts.json` 和 `species-prompts.json`。用户参考图片仅作风格依据，没有复制为背景或放入样板目录。旧 P1 素材未被使用。

- 脚本语法、9 个页面/样式/脚本引用与六张纹理的 HTTP 加载检查通过。
- 三种鱼、两只水母、10/18/30 总量持续模拟与追食消耗检查通过。
- Safari 已加载并检查实际完整场景、连续纹理边缘、暂停/恢复、投喂提示、美术说明与纯净观赏。
- 1440×900 和 390×844 的 Canvas 降级场景渲染已检查，位于 `qa/*-fallback.png`；这些是降级渲染帧，不是 Safari 截图，也不证明移动设备帧率。
- 自动化控制下 Safari 把标签页报告为后台状态，前台连续动画帧率未测量。请将样板标签页置于前台判断实际动态观感。

正式生产构建只收集根目录 `index.html`、`css/`、`js/`、`assets/`，因此本目录不在现有线上产物中。扩展到正式项目前，等待用户判断美术方向。
